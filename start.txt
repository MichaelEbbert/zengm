# ─────────────────────────────────────────────
#  HOW TO START ZENGM (Windows Desktop)
# ─────────────────────────────────────────────
# Three terminals are needed. Open each with:
#   Start → "Windows PowerShell" (or Windows Terminal)
# Run each command from the zengm project folder.
# Electron is REQUIRED — without it, game data is not saved.
# ─────────────────────────────────────────────

# STEP 1 (optional) — Sidecar on another machine
# Skip if no Linux machine is available; play-calling falls back to random.
# Run this SSH'd into the Linux machine, inside the zengm-coach/ folder:
#
#   uvicorn main:app --host 0.0.0.0 --port 3004

# STEP 2 — Dev server  (PowerShell, this machine)
# Pick the line that matches which machine is running the sidecar.
# If you skipped Step 1, use any line — COACH_SIDECAR_URL is ignored when the sidecar is unreachable.

# Sidecar on this machine (Windows Desktop, 192.168.1.18):
$env:COACH_SIDECAR_URL="http://192.168.1.18:3004"; $env:SPORT="football"; node --run dev

# Sidecar on laptop (192.168.1.142):
$env:COACH_SIDECAR_URL="http://192.168.1.142:3004"; $env:SPORT="football"; node --run dev

# Sidecar on ThinkPad/Linux (192.168.1.29):
$env:COACH_SIDECAR_URL="http://192.168.1.29:3004"; $env:SPORT="football"; node --run dev

# Wait for the dev server to print "ready" before continuing to Step 3.

# STEP 3 — Electron  (NEW PowerShell window, this machine)
# This opens the game window and enables SQLite storage.
node --run electron

# The Electron window opens automatically — no browser needed.
# Leave this terminal open while playing.

# ─────────────────────────────────────────────
#  ELECTRON HTTP API
#  Starts automatically with Electron.
#  Base URL: http://127.0.0.1:3001
# ─────────────────────────────────────────────
# GET  /status                  - current phase and season
# POST /sim/day                 - sim one day
# POST /sim/week                - sim one week
# POST /sim/month               - sim one month
# POST /sim/untilPlayoffs       - sim through regular season
# POST /sim/throughPlayoffs     - sim through playoffs
# POST /sim/untilDraft          - advance to draft
# POST /draft/onePick           - sim one AI draft pick
# POST /draft/untilEnd          - sim rest of draft
# POST /draft/pick              - user draft pick: body {"pid": 123}
# POST /sim/untilResignPlayers  - advance to resign players phase
# POST /sim/untilFreeAgency     - advance to free agency
# POST /sim/untilPreseason      - sim through free agency
# POST /sim/untilRegularSeason  - advance to regular season start
# GET  /query                   - SQL query endpoint (not yet implemented)
